## Site text (erdosproblems.com/80, fetched 2026-08-26)
f_c(n) = max m such that every n-vertex graph with ≥ cn² edges, each edge in ≥1 triangle,
has a book of size m. "Estimate f_c(n). In particular, is it true that f_c(n)>n^ε ...?
Or f_c(n) ≫ log n?" Comments: Alon–Trotter f_c ≪ √n for c<1/4; Szemerédi regularity ⇒
f_c → ∞; Edwards/Khadzhiivanov–Nikiforov f_c ≥ n/6 for c>1/4; **Fox–Loh [FoLo12]:
f_c(n) ≤ n^{O(1/log log n)} for ALL c<1/4, "disproving the first conjecture of Erdős."**
Site marks #80 OPEN (the log question and exact growth remain open).

## Lean reading and the defect
`erdos_80 : ∀ c ∈ (0,1/2), ∃ ε > 0, ∀ᶠ n, (n:ℝ)^ε < f c n`, category `research open`.

This is the ε-question asserted for every c in (0,1/2). But:
- For every c < 1/4 it is **false**: Fox–Loh's upper bound n^{O(1/loglogn)} = o(n^ε) for
  every ε>0, so no positive ε works. The disproof is quoted on the problem's own page.
- For c > 1/4 it is true via f_c ≥ n/6 (Khadzhiivanov–Nikiforov).
So the literal Lean statement has truth value False (witness any c ∈ (0,1/4)), yet is filed
`research open`. This is a status-sync/wrong-category defect of the productive kind: the
statement should be re-scoped (e.g. to c ∈ [1/4, 1/2), or replaced by the still-open log
question which the file already carries as `erdos_80.variants.log`) and re-categorized.

Secondary (comment-only) defect: the file preamble duality claim
"`r ≤ f c n` and `Erdos600.eFunction n r ≤ c * n^2` say the same thing" needs the ceiling:
the correct equivalence is r ≤ f_c(n) ⟺ e(n,r) ≤ ⌈c n²⌉ (nonempty-class regime).
Counterexample to the un-ceiled form: n=4, c=0.2 — f_{0.2}(4)=2 yet e(4,2)=4 > 3.2.
Verified by exhaustive enumeration (EP600.md); also degenerate regimes (n≤2 or empty
admissible class, e.g. c=0.4,n≤5) break the biconditional from the other side, consistent
with the docstring's own feasibility remark.
