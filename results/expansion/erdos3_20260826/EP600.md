# EP 600 — audit (@ `2411d22e`, `FormalConjectures/ErdosProblems/600.lean`)

**Status: AUDIT_CLEAN + exact e(n,r) table to n=7 (HOLD_BOUNDED).**

## Site text (erdosproblems.com/600, fetched 2026-08-26)
e(n,r) minimal such that every n-vertex graph with ≥ e(n,r) edges, each edge in ≥1 triangle,
has an edge in ≥ r triangles. Two open questions: e(n,r+1) − e(n,r) → ∞? and e(n,r+1)/e(n,r)
→ 1? (r fixed ≥2). Ruzsa–Szemerédi: e(n,r)=o(n²) fixed r. OPEN.

## Lean reading
`Erdos600Prop`/`eFunction` match the site word-for-word; parts .i/.ii are exactly the two
site questions; Ruzsa–Szemerédi variant recorded. Faithful. The hypothesis is *every* edge in
a triangle (vacuous on edgeless graphs) — our first solver draft got this wrong
(max-book ≥ 1 instead of min-book ≥ 1) and produced e(4,2)=5; the corrected reading gives
e(4,2)=4, and the DB-sanity cross-check (two independent implementations) settles it.
This is exactly the class of subtle-quantifier readings the campaign's gates exist for.

## Duality with EP80 (checked numerically)
Correct equivalence (admissible class nonempty): **r ≤ f_c(n) ⟺ e(n,r) ≤ ⌈c·n²⌉**,
verified exhaustively over the computed tables for c ∈ {0.1,0.2,0.25,0.3,0.4}, r ∈ {2..5},
n ≤ 7. The un-ceiled form stated in 80.lean's header comment (`eFunction n r ≤ c * n^2`)
is off by the rounding whenever cn² ∉ ℕ — counterexample n=4, c=0.2 (f=2 but e=4 > 3.2);
see EP80.md. Not a theorem-statement defect (comment-only).
