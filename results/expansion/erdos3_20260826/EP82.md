## Site text (erdosproblems.com/82, fetched 2026-08-26)
$F(n)$ maximal such that every graph on $n$ vertices contains a regular induced subgraph on at
least $F(n)$ vertices. Conjecture (Erdős–Fajtlowicz–Stanton): $F(n)/\log n\to\infty$. Known:
**F(5)=3, F(7)=4**; Ramsey gives $F(n)\gg\log n$; Bollobás/AKS07/Dyson–McKay upper bounds;
inverse function data G(1)=1, G(2)=2, G(3)=5, G(4)=7 [FMRS95], G(5)=17, G(6)≥21, G(7)≥29.
OPEN.

## Lean reading
`F n = sSup {k | ∀ G : SimpleGraph (Fin n), ∃ S : Subgraph G, IsRegularInduced S ∧ k ≤ S.verts.ncard}`
with `IsRegularInduced S := S.IsInduced ∧ ∃ k, S.coe.IsRegularOfDegree k`; main theorem is
exactly `Tendsto (fun n => F n / log n) atTop atTop`. Faithful to the site sentence-by-sentence:
- "regular induced subgraph on at least F(n) vertices" ↔ sSup over guaranteed vertex counts ✓.
- Degree-0 regularity makes every independent set and every singleton count — matches the
  literature's reading (t(n) "trivial" subgraphs are empty/complete; independent sets count).
- The AKS07 upper-bound variant matches the site's bound form.
