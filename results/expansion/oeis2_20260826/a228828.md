# A228828 — audit (n²+π(n) prime infinitely often)

**Class: HOLD.** Gates: a ✓, b ✓, d ✓.

OEIS (`oeis_pages/A228828.html`): "%N Numbers n such that n^2 + pi(n) is
prime", "%C Conjecture: the sequence is infinite." The Lean enumerates the
sequence via `n.nth` and asserts `{a n | n}.Infinite` — same claim, faithful.
Test values a(0)=2, a(1)=3, a(2)=7 verified by hand (1+0=1 not prime,
4+1=5, 9+2=11).

Note for the record: an upstream PR (#3393) claiming to prove this infinity
was closed unmerged (the claim would be a significant open-problem result);
consistent with our assessment that the declaration is genuinely open. No
finite witness exists for an infinitude claim; nothing to do computationally.
