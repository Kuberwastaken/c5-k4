## Falsifiability analysis

An O(n³) statement fails only if for every C there is n with a(n) > C·n³ — no
finite witness can settle it, so this lane admits no computational crossing by
design (METHOD gate: certificate-shape check). The OEIS b-file reaches n=10000
(PRPs after 8025). No status defect found.

Note (recorded, not claimed): the Lean docstring's justification "any larger m
would make 2^n − m = 0" is sloppy prose but does not affect the formal object,
which filters over the finite range [0, 2^n] and takes the first hit.
