## Independent derivation (before novelty check)

Σ_{k=1}^n {n/k} = nH_n − Σ_{k=1}^n ⌊n/k⌋, and the second sum is the Dirichlet
divisor summatory function D(n) = Σ_{m≤n} d(m) = n log n + (2γ−1)n + O(√n)
(Dirichlet 1849). With H_n = log n + γ + O(1/n): the sum is (1−γ)n + O(√n),
so a(n)/n → 1−γ — provable from classical estimates, not genuinely open.
