## Source vs declaration

OEIS (`oeis_pages/A110475.html`): %N matches Lean's `(d−1)+c` definition;
test values match %S head. The conjecture comment is verbatim:
"It is conjectured that 1,2,3,4,5,6,7,9,11 are the only positive integers which
cannot be represented as the sum of two elements of indices n such that a(n) = 1."

Reading analysis (gate b): "elements of indices n such that a(n)=1" admits
(i) m = x+y with a(x)=a(y)=1 (Lean's reading) or (ii) m as an index whose value…
(ii) is not well-formed; (i) is the only sensible formalization and matches the
exceptional-set phrasing. Lean `∃ x y, a x = 1 ∧ a y = 1 ∧ m = x + y` ✓.

Here S = {n : a(n)=1} = {p^k : k≥2} ∪ {squarefree pq}.

  members verified unrepresentable.
- Independent (`a110475_independent.py`, trial-division factorization + direct
  pair scan): same conclusion to B=2·10^5; spot checks 15=6+9, 21=6+15,
  27=6+21 representable; 4, 11 not.
- Two implementation bugs were caught by this cross-checking during the run

  agreement documented.
