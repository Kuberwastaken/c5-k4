## Q1 (next prime): bracket

Hand-proved prefilter: term parity = base parity, so a(n) ≡ ⌈n/2⌉ (mod 2);
an odd prime forces n ≡ 2 or 3 (mod 4). Additional small-prime divisibility
filters (mod p evaluation, no big ints). Results:

- Every n ∈ [3, 95] is composite: even values provably composite; odd values
  failing mod-p filters carry an explicit small-prime divisor; the survivors
  n ∈ {10, 23, 30, 34, 39, 43, 46, 47, 51, 59, 91, 95} (up to ~15k digits)
  were tested composite by sympy BPSW (`isprime`).
- The search aborted inside the PRP test of the next survivor n=106 (~20k
  digits) at the 60 s cap → n ≥ 106 unknown.

Bracket: **no prime for 3 ≤ n ≤ 95**; nothing claimed beyond.

## Q2 (first square after 1): bracket with certificates

For each n, a(n) must be a quadratic residue (or 0) modulo every prime.
Scanning n ≤ 2500 against primes {3,…,41}, exactly one candidate survived:
n = 1914. Killed by p=113 (a(1914) is a non-residue mod 113 — a proof).
Every other n fails at least one of {3,…,41}.

Bracket: **no square for 3 ≤ n ≤ 2500**, each exclusion backed by an explicit
modular obstruction (checkable from the committed scripts).
