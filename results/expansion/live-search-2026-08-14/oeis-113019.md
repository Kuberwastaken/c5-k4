# OEIS A113019: the third fixed point is `9^9`

Date: **2026-08-14 UTC**  
Disposition: **INTENDED QUESTION ANSWERED; source correction candidate**

## Exact result

The literal A113019 function raises the number of decimal digits of `n` to
the digital root of `n`.  Besides the two fixed points named by the source,
`1` and `32`, it has

```text
n = 387420489 = 9^9.
```

This number has nine decimal digits and digital root nine because its digit
sum is `45`, whose digit sum is `9`.  Therefore `a(n)=9^9=n`, while
`n != 1` and `n != 32`.

## Complete fixed-point classification

For any positive fixed point, let `d` be its decimal digit count and `r` its
digital root.  The definition forces

```text
n = d^r, with 1 <= r <= 9.
```

For `1 <= d <= 10`, exact enumeration gives precisely

| `n` | digit count `d` | digital root `r` |
|---:|---:|---:|
| 1 | 1 | 1 |
| 32 | 2 | 5 |
| 387420489 | 9 | 9 |

No `d>=11` can work.  Exactly, `11^9 < 10^10`; moreover
`((d+1)/d)^9 <= (12/11)^9 < 10` for every `d>=11`.  Induction gives
`d^9 < 10^(d-1)`, so every `d^r` has fewer than `d` decimal digits.

Thus the three displayed values are all fixed points of the literal function.
