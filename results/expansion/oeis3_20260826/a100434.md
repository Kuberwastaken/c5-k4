## Counterexample (gate c)

(`scripts/a100434_dement.py`; logs `a100434_run1.log`, `a100434_run2.log`)

- At n = 0: c(0)+d(0) = 1+2 = 3, but b(0) = c(1) = −3. So conjecture1 is FALSE.
- e(0)+f(0) = d(0)/2 + d(1)/2 = 1+2 = 3 ≠ −3: conjecture2 FALSE.
- g(0)+a(0) = 0+3 = 3 ≠ −3: conjecture3 FALSE. Worse, conjecture3 at even n
  CONTRADICTS the file's own proven lemma `a_even` plus g(2n)=0:
  g(2n)+a(2n) = −c(2n+1) = −b(2n).
- Failures repeat at every even n (residuals ±2|c+d| pattern), n = 0..28 tabulated.

## What is actually true (verified to n = 100, exact arithmetic)

- Three-way identity: c(n)+d(n) = e(n)+f(n) = g(n)+a(n) for ALL n ≥ 0.
- Signed form: (c+d)(n) = (−1)^(n+1) · b(n). Dement's sign convention
  ("apart from signs") absorbed the alternation; the Lean port literalized it.
