A100800
Let f(n) = n + sum of the digits of n. If f(n) is multiple of n then a(n)= f(n) else a(n) = f(f(f(n)))... until one gets a multiple of n; a(n) = 0 if no such number exists.

%N Let f(n) = n + sum of the digits of n. If f(n) is multiple of n then a(n)= f(n) else a(n) = f(f(f(n)))... until one gets a multiple of n; a(n) = 0 if no such number exists.

%C Conjecture: No term is zero.

%e a(10) = 130, f(10) = 10 + 1 = 11, f(f(10)) = f(11) = 13,... we get the sequence 10,11,13,17,25,32,37,47,58,71,79,95,109,119,130,...
