Number of ways to write n as x*(x+1)/2 + y*(3*y+1)/2 + z*(5*z+1)/2 with x,y,z nonnegative integers.

%T 3,2,5,2,3,7,3,7,2,6,3,5,6,7,2,4,6,3,7,2,8,4,2,6,6,3,8,3,4,6,3,7,5,6,

%N Number of ways to write n as x*(x+1)/2 + y*(3*y+1)/2 + z*(5*z+1)/2 with x,y,z nonnegative integers.

%C Conjecture: a(n) > 0 for all n = 0,1,2,..., and a(n) = 1 only for n = 0, 1, 2, 4, 7, 9, 22.

%C It was proved in arXiv:1502.03056 that each n = 0,1,2,... can be written as x(x+1)/2 + y(3y+1)/2 + z(5z+1)/2 with x,y,z integers. The author would like to offer 135 US dollars as the prize for the first proof of the conjecture that a(n) is always positive.

%C See over 400 similar conjectures in the linked a-file.

%H Zhi-Wei Sun, <a href="/A287616/b287616.txt">Table of n, a(n) for n = 0..10000</a>

%H Yichuan Cao, Dakai Guo, Ruichen Qiu, Ruyong Feng, and Xiao-Shan Gao, <a href="https://arxiv.org/abs/2606.26035">Every Nonnegative Integer Is a Sum of a Triangular, a Pentagonal, and a Heptagonal Number</a>, arXiv:2606.26035 [math.NT], 2026. See pp. 1-2, 12 (Lean formalization).

%H Yichuan Cao, Ruichen Qiu, Junqi Liu, Jiaqi Wang, Dakai Guo, Ruyong Feng, Lihong Zhi, and Xiao-Shan Gao, <a href="https://arxiv.org/abs/2607.04394">MechMath Agent Team: LLM Driven Agents for Mathematical Research</a>, arXiv:2607.04394 [cs.AI], 2026. See pp. 15-16.

%H Zhi-Wei Sun, <a href="/A287616/a287616_3.txt">List of conjectural tuples (a,b,c,d,e,f) with {x*(ax+b)/2 + y*(cy+d)/2 + z*(ez+f)/2: x,y,z = 0,1,2,...} = {0,1,2,...}</a>

%H Zhi-Wei Sun, <a href="https://doi.org/10.4064/aa127-2-1">Mixed sums of squares and triangular numbers</a>, Acta Arith. 127 (2007), 103-113.

%H Zhi-Wei Sun, <a href="https://doi.org/10.1007/s11425-015-4994-4">On universal sums of polygonal numbers</a>, Sci. China Math. 58 (2015), No. 7, 1367-1396.

%e a(4) = 1 since 4 = 1*(1+1)/2 + 0*(3*0+1)/2 + 1*(5*1+1)/2.

%e a(7) = 1 since 7 = 0*(0+1)/2 + 2*(3*2+1)/2 + 0*(5*0+1)/2.

%e a(9) = 1 since 9 = 3*(3+1)/2 + 0*(3*0+1)/2 + 1*(5*1+1)/2.

%e a(22) = 1 since 22 = 5*(5+1)/2 + 2*(3*2+1)/2 + 0*(5*0+1)/2.

%t TQ[n_]:=TQ[n]=IntegerQ[Sqrt[8n+1]];

%t Do[r=0;Do[If[TQ[n-x(3x+1)/2-y(5y+1)/2],r=r+1],{x,0,(Sqrt[24n+1]-1)/6},{y,0,(Sqrt[40(n-x(3x+1)/2)+1]-1)/10}];Print[n," ",r],{n,0,80}]
