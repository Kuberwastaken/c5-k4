## Declaration under audit

Lean defines `b n := (3*n).choose n / (2*n+1)` (natural division) and sorries
`frac n = b (n+1) / b n` for n ≥ 1.

## Findings

**(1) Wrong sequence in Lean.** `b` computes C(3n,n)/(2n+1) = **A001764**
(ternary trees; 1,1,3,12,55,273,...), NOT A005156 (vertically symmetric ASMs;
1,1,3,26,646,...). Verified identical to A001764 for all n ≤ 60 by an
independent prime-exponent computation of C(3n,n)/(2n+1).

**(2) The Lean statement is FALSE at the first guarded value:** n=1 gives
frac 1 = C(4,2)/(2·C(3,2)) = 1 while b(2)/b(1) = 3/1 = 3. One wrong term ⇒
refuted (also fails at every tested n ≤ 49).

**(3) OEIS's own comment has the wrong SHIFT.** With true A005156,
frac(n) ≠ A005156(n+1)/A005156(n) at every tested n; the correct relation is
**frac(n) = A005156(n)/A005156(n−1)**:
- exact equality for n = 1..66 against b005156.txt values (Fraction path);
- SYMBOLICALLY: frac(n) reduces to (6n−2)!(2n−1)!/(2·(4n−1)!(4n−2)!), which is
  exactly the ratio term of the Razumov–Stroganov product formula
  A005156(n) = 2^(−n)∏_{k=1..n} (6k−2)!(2k−1)!/((4k−1)!(4k−2)!),
  a formula PROVED by Kuperberg per the A005156 %F line.
So the corrected identity is not a conjecture at all — it is an immediate
theorem of the known product formula.
